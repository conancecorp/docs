# Types de produits personnalisés

Le **type** d'un [produit](/features/products) est sa catégorie : OPCVM, SCPI, Assurance-vie… Il sert à la répartition *Commissions par type de produit* du tableau de bord et aux filtres.

## Types livrés

OPCVM, SCPI, Assurance-vie, FCPI, FIP, PER, FCPR, EMTN, Autres.

## Ajouter un type

*Paramètres → Types de produits personnalisés* :

1. **Nouveau type de produit**
2. Saisissez le libellé (ex. « Actions européennes », « Obligations », « Private equity », « Girardin »)
3. **Créer**

Un type se crée aussi **à la volée** dans le formulaire produit (champ *Type de produit* : sélectionner ou saisir) et à l'étape *Configuration produits* de l'import.

## Modifier, supprimer

Un type personnalisé se renomme. Il se supprime s'il n'est plus utilisé par aucun produit.

::: tip Évitez les variantes
« Assurance vie », « Assurance-vie » et « AV » feraient trois catégories dans les graphiques. Utilisez les types livrés quand ils conviennent, et un seul libellé par catégorie nouvelle.
:::

## Ne pas confondre

| | Où | Pour quoi |
|---|---|---|
| **Type de produit** | Ici | La catégorie d'un produit |
| **Produit** | [Produits](/features/products) | Le support lui-même, rattaché à un partenaire |
| **Activité** | [Activités personnalisées](/settings/custom-activities) | Le régime réglementaire (CIF, Courtage…) |
