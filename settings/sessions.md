# Sessions actives

*Paramètres → Sessions actives* liste les connexions ouvertes sur votre compte et permet de les fermer à distance.

## Informations affichées

Pour chaque session : type d'appareil, navigateur et système, adresse IP, date de connexion et de dernière activité, et l'étiquette **Session actuelle** pour celle que vous utilisez.

## Révoquer une session

Cliquez sur **Révoquer cette session** : elle est fermée immédiatement, l'appareil devra se reconnecter.

**Révoquer toutes les autres sessions** ferme tout sauf la session en cours.

::: tip Session inconnue
Une session que vous ne reconnaissez pas ? Déconnectez-la, changez votre [mot de passe](/settings/profile) et activez la [2FA](/settings/security) si ce n'est pas déjà fait.
:::

## Durée des sessions

Une session expire d'elle-même après une période d'inactivité. Se déconnecter (menu utilisateur → **Déconnexion**) la ferme tout de suite.
