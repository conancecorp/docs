# Vue d'ensemble des fonctionnalités

Conance couvre toute la chaîne des commissions d'un cabinet : les faire entrer, les fiabiliser, les analyser, les déclarer.

## Faire entrer les données

| Fonctionnalité | Description | Guide |
|----------------|-------------|-------|
| Import | Assistant en quatre étapes pour les bordereaux CSV, Excel, OpenDocument et PDF | [Import de données](/features/import/) |
| Extraction PDF | Conversion d'un PDF en tableau éditable puis en CSV importable — gratuit, IA en secours | [Import depuis un PDF](/features/import/pdf) |
| Configurations | Mapping mémorisé par format de fichier, modèles Conance pour les partenaires connus | [Configurations sauvegardées](/features/import/saved-configs) |
| Correspondances | Rapprochement des numéros de contrat approximatifs, associations mémorisées | [Correspondances de contrats](/features/import/smart-matching) |
| Annulation | Retrait intégral de ce qu'un import a écrit, y compris hors commissions | [Annuler un import](/features/import/undo) |

## Fiabiliser

| Fonctionnalité | Description | Guide |
|----------------|-------------|-------|
| Commissions, contrats, clients, conseillers, partenaires, produits | Référentiels avec recherche serveur, filtres croisés, colonnes personnalisables | [Gestion des données](/features/commissions) |
| Fusion de contrats | Regroupement des doublons, alias automatiques | [Fusion de contrats](/features/contracts/merge) |
| Actions en masse | Modification et suppression sur une sélection ou sur tout un filtre | [Actions en masse](/features/bulk-actions) |
| Natures et types d'opération | Traduction des libellés de chaque partenaire vers des natures communes, extensibles | [Paramètres](/settings/) |

## Analyser

| Fonctionnalité | Description | Guide |
|----------------|-------------|-------|
| Tableau de bord | Volumes, répartitions, derniers mouvements | [Tableau de bord](/features/dashboard) |
| Pilotage | Encours retenu par les partenaires, production, couverture | [Pilotage](/features/pilotage/) |
| Commissions attendues | Contrats dont la commission n'est pas venue, attentes déclarées, écarts | [Commissions attendues](/features/pilotage/expected-commissions) |
| Prévisionnel | Combien cette année, et quand — total annuel et échéances par contrat | [Prévisionnel](/features/pilotage/forecast) |
| Export et tableau croisé | CSV filtré, tableau croisé dynamique avec détail par cellule | [Export de données](/features/export) |
